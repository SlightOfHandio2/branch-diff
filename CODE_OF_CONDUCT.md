# Code of conduct

Diff Branch is committed to a welcoming, respectful, and harassment-free community.

## Expected behavior

- Be considerate and constructive.
- Critique ideas and code, not people.
- Respect different backgrounds, viewpoints, and levels of experience.
- Accept feedback gracefully and focus on what is best for the project.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate intimidation, doxxing, and sustained disruption are not tolerated.

## Enforcement

Maintainers may edit or remove contributions and temporarily or permanently restrict participation when behavior violates these expectations. If you experience or witness unacceptable behavior, report the relevant GitHub content privately to the repository maintainers or through GitHub's reporting tools. Reports will be handled as confidentially as practical.
