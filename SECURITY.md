# Security policy

## Supported versions

Security fixes are made against the latest released version of Branch Diff.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository:

https://github.com/SlightOfHandio2/branch-diff/security/advisories/new

Include reproduction steps, the potential impact, and any suggested mitigation. You should receive an acknowledgement within seven days. Please allow time for a fix before public disclosure.
